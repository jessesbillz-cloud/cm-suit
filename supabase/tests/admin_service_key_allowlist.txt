revoke-member

send-transmittal

invite-bidders

issue-addendum

extract-bid

access

submit-daily
# Writes the transmittal, share links and email_outbound for the author (who may lack transmittals.send); the report,

email-daily
# Stores the signed IR PDF (storeGeneratedPdf: storage + files row) and records it (ir_attach_pdf, service-only), reads

ir-pdf

ir-send

delivery-board

key-login
# Stores the RFI PDF (storeGeneratedPdf: storage + files row) and records it (rfi_attach_pdf, service-only), reads photo,

# rfi_authorize_file() run as the user first.
rfis
# Reads the company logo bytes from private storage (orgs.logo_path read as the caller, who is on one of its jobs) for

timesheets
# Public endpoint §6.4 #4: the request link and the inspector's hub. Tokens are checked by service-role-only SQL
# (link_request_*), which answers the job name / the hub's job names and records a sub invite only for the address of

# Revs from the link (0057): a request's private receipt is checked by service-role-only SQL (link_request_map*) before
# the function reads that request's sheet row and bytes, the signer's signature image, the job's name and zone and the
# map's ir_maps row, gets the Reports folder (ir_folder_make), stores the map (storeGeneratedPdf, the one ensureMap of

# and per IP.
request-link
# Reads the original PDF's bytes from private storage, stores the stamped copy (storeGeneratedPdf: storage + files row)

# and signs view URLs; the permit is read as the user, and
# requireCapability('permits.manage'), the signing re-confirmation, permit_stamp_source() (authorize_download inside),
# permit_record_stamped_set() or permit_approved() run as the user first.
permit-stamp
# Revs inspection maps: reads the sheet's files row and bytes, the signer's signature image and the map's ir_maps row,
# gets the Reports folder (ir_folder_make: the requester may lack ir.decide), stores the map (storeGeneratedPdf), records
# it (ir_map_attach, service-only) and signs URLs; ir_map_context() runs as the user first (it refuses anyone who can't
# see the request), and every URL is handed out after authorize_ir_file() as the user; a Revs plan sheet's URL (0059)
# only after authorize_rev_sheet() as the user.
ir-map
# Public endpoint §6.4 #8: the meeting sign-in page. The meeting's token is checked by service-role-only SQL

meeting-signin

safety-meeting

schedule-import

requirements-extract
